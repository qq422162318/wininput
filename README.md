# WinInput

适用于 Windows 10 1803 的远程输入工具。接收端运行在被控电脑，发送端运行在另一台电脑。

- 接收端：监听 TCP，验证共享密钥后，把文字/组合键发送到接收端当前前台窗口。
- 发送端：填写接收端地址、端口和共享密钥，输入文字后发送；支持 Shift/Ctrl/Alt + F1-F12 以及普通键。
- 仅监听指定地址和共享密钥，不做远程桌面或文件传输。

## 构建

需要 Visual Studio 2019/2022 的 .NET Framework 4.0 开发工具，在此目录执行：

```bat
msbuild WinInput.sln /p:Configuration=Release
```

输出位于 `src\\WinInput.Receiver\\bin\\Release` 和 `src\\WinInput.Sender\\bin\\Release`。

## 使用

1. 接收端设置监听地址（局域网使用 `0.0.0.0`）、端口和共享密钥，点击启动。
2. Windows 防火墙仅允许来自可信局域网的 TCP 端口；不要把端口暴露到公网。
3. 发送端填写接收端 IP、端口、相同密钥，点击连接。
4. 让目标软件的输入框获得焦点；发送端输入文字点击“发送文字”。组合键按钮会发送到接收端当前前台窗口。

共享密钥至少 16 个字符。协议限制单条文字 64 KiB，避免异常请求占用内存。
