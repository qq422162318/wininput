# WinInput 原生版

此目录的 `native` 版本完全使用 C++ Win32 + Winsock + `SendInput`，不依赖 .NET Framework 或 Qt，适合 Windows 10 1803。

在 VS 2022 Developer Command Prompt 中执行：

```bat
cd /d F:\wininput\native
build.bat
```

只更新发送端（接收端正在运行时）：

```bat
build.bat sender
```

输出：

```text
F:\wininput\native\bin\WinInput.Receiver.exe
F:\wininput\native\bin\WinInput.Sender.exe
```

接收端监听 TCP 18765，默认密钥为 `1234567890123456`；发送端默认地址为 `192.168.0.102`，默认密钥相同。两端都可在界面中修改预填值；程序不会保存后续修改。默认密钥写在 EXE 中，不应视为保密凭据。连接后，仅发送端窗口位于前台时捕获并转发键盘的按下/抬起事件，包括组合键；失焦时释放按住的键。发送端不再提供文字输入框或按键按钮。鼠标仍用于关闭窗口；普通程序无法转发 Ctrl+Alt+Del 等安全桌面按键。两端均需更新到新版本。连接后可使用“推送剪贴板”和“拉取剪贴板”按钮双向同步剪贴板：推送是把发送端剪贴板写入接收端，拉取是把接收端剪贴板写入发送端。支持剪贴板中的全局内存格式，包括文本、DIB/DIBV5 位图、TIFF、文件名列表（CF_HDROP）以及注册类命名格式；单次总大小上限为 10 MB，超过或无法读取的格式会被跳过并在状态栏提示。文件名列表（CF_HDROP）会把每个文件的内容一并传输（总量受 10 MB 限制）：接收端把文件写入临时目录 `…\Temp\WinInput\`，并以这些本地副本重建文件名列表，这样在接收端粘贴文件时不会再提示找不到。若文件过大或无法读取，则回退为只传路径（此时接收端粘贴仍可能提示找不到源文件）。

不要把端口暴露到公网；只在可信局域网使用，并在 Windows 防火墙中限制来源地址。
